RESTful API – Blog Management System

Using MERN Stack Technologies

Task Title

RESTful API

Description

This assignment describes a RESTful API developed using MERN Stack technologies to manage blog data. The API follows REST principles and handles Posts, Authors, Comments, Categories, and Tags. Dummy data is used for academic purposes.

Technologies Used (MERN Stack)

  • MongoDB – Database
  • Express JS – Backend Framework
  • React JS – Frontend (API Consumer)
  • Node JS – Server Environment

API Resources

  • Posts
  • Authors
  • Comments
  • Categories
  • Tags

RESTful Endpoints

Resource Method Endpoint
Authors GET /authors
Authors POST /authors
Categories GET /categories
Categories POST /categories
Tags GET /tags
Tags POST /tags
Posts GET /posts
Posts POST /posts
Comments GET /comments/{postId}
Comments POST /comments

REST Principles Used

  • Resource-based URLs
  • HTTP methods (GET, POST)
  • Stateless communication
  • JSON data format

Conclusion

This RESTful API design demonstrates how MERN Stack technologies can be used to manage blog-related data efficiently while following REST architecture principles.
